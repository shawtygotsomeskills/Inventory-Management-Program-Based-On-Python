# 📦 Inventory Management System
A simple Python-based Inventory Management System designed as a Class 11 Python Capstone Project. It allows users to manage stock, record sales, search for items, export reports, and visualize sales data through a graph.

🚀 Features

The system provides the following options:

1.Add Item – Add new products to the inventory with their details.
2.View Inventory – Display all available items and their stock.
3.Search Item – Search for a particular product in the inventory.
4.Sell Item – Record the sale of an item and automatically update its stock.
5.View Sales Summary – View total sales and sales-related information.
6.Export Report to CSV – Export inventory/sales data into a CSV file for easy record keeping.
7.Show Sales Graph – Generate a graphical representation of sales.
8.Exit – Close the Inventory Management System.

🛠️ Technologies Used
1.Python
2.CSV – For exporting reports
3.Matplotlib – For displaying sales graphs
4.Lists / Dictionaries – For storing inventory data
5.Functions – For organizing the program
6.File Handling – For saving and exporting data
